
如何编译
在macOS上安装arm64的homebrew, 然后安装arm64位的gstreamer

安装方法
cd /opt/homebrew/bin
./brew install gstreamer


生成环境的GStreamer.framework和devel的GStreamer.framework目录结构和内容是不同的
